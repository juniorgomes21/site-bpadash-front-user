# BPADASH - User Frontend

Frontend application for the BPADASH business management platform.

This project provides the user-facing interface of the platform, integrating with backend APIs to display and manage business-related data and features.

## Features

- User-facing web interface
- REST API integration
- Business data visualization
- Date-based data filtering
- Client-side state management
- Routing and navigation
- Responsive UI components
- Form handling and validation
- Internationalization support

## Technologies

- React
- JavaScript
- Vite
- Redux
- Redux Saga
- Axios
- Material UI
- Tailwind CSS
- React Router
- Formik
- Firebase
- i18next

## Architecture

The application follows a component-based React architecture with separate areas for:

- Pages
- Reusable components
- API services
- Application state
- Routing
- UI components
- Business-specific features

The frontend communicates with backend services through HTTP APIs using Axios.
